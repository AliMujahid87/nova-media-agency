# NOVA Media Agency - Style Guide

This document contains the brand assets and style guidelines for NOVA Media Agency.

## 🎨 Color Palette

| Color | Hex Code | Usage |
| :--- | :--- | :--- |
| **Amber/Gold** | `#FFC107` | Primary Brand Color (Logo, Buttons) |
| **Light Amber** | `#FFEA6A` | Gradient Start (Navbar Logo) |
| **Dark Orange** | `#FF9800` | Gradient End (Navbar Logo) |
| **Black** | `#000000` | Main Background |
| **Zinc 900** | `#18181b` | Secondary Backgrounds / Borders |

## 🔠 Typography

*   **Headings**: `Lexend` — A modern, geometric sans-serif font for bold, premium-feel titles.
*   **Body**: `Inter` — High-readability sans-serif font for clear communication.

## 🖼️ Media Assets

*   **[logo-icon.jpeg](./logo-icon.jpeg)**: Original bitmap icon for profile pictures and social media.
